# Research Team GitHub Website

A Jekyll-based research-team dashboard designed for GitHub Pages.

## Quick start

1. Create a GitHub repository named `research-team` (or any name you prefer).
2. Upload all files from this folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to build the site.
7. Your site will normally be available at:
   `https://YOUR-USERNAME.github.io/repository-name/`

## Important customization

Edit `_config.yml` to change the site title.

Edit `index.md` for the homepage.

Add projects to `_projects/`.

Add researchers to `_people/`.

Edit `publications.md`, `deadlines.md`, and `resources.md`.

## Local preview (optional)

If Ruby/Jekyll is installed:

```bash
bundle install
bundle exec jekyll serve
```

Then open the local address shown by Jekyll.

## Privacy
